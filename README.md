# 映照

一个专注于自我观察的极简备忘录应用。

## 功能特点

- 🔐 **密码保护**：使用密码锁定应用，保护个人隐私
- 🌙 **主题切换**：支持深色/浅色主题，适应不同使用场景
- 📝 **结构化记录**：
  - 日期、天气、心情
  - 事实记录、情绪反应
  - 模式识别、改进实验
  - 标签管理
- 🔍 **搜索功能**：快速查找历史记录
- 💾 **数据管理**：本地存储 + 云同步（可选）
- 📤 **导入导出**：支持JSON格式数据迁移
- 📱 **PWA支持**：可安装为原生应用，离线使用

## 安装使用

1. 直接在浏览器中打开 `index.html`
2. 设置密码并登录
3. 开始记录你的自我观察

## 核心理念

"记录不是为了证明什么，只是为了看清。"

映照帮助你：
- 客观记录发生的事实
- 观察自己的情绪反应
- 识别行为模式
- 设计小实验促进成长

## 技术栈

- HTML5
- CSS3 (玻璃拟态设计)
- JavaScript (ES6+)
- PWA (渐进式Web应用)
- 本地存储 (localStorage)

## 数据安全

- 所有数据默认存储在本地浏览器中
- 可选择开启云同步功能
- 支持数据导出备份
